❓ VAII System Operation Guide

VAII features two operational modes: VAII Native for real-time web utilities and integrations, and Gemini Ecosystem for deep conversational threads.

🌐 VAII Native Commands & Syntax

  • Live Music Streaming & Spotify Hub: Type play [song] or stream song [song] (e.g. play Blinding Lights) to load 30s preview audio with Spotify and YouTube Music streaming links.
  • NASA Mars Rover Telemetry: Type mars, rover, curiosity, or perseverance to fetch live Mars surface photos, Martian Sol dates, and landing telemetry.
  • YouTube Video Hub & Player: Type yt [query] or youtube [query] (e.g. yt Veritasium, yt Kurzgesagt) to load an inline video player card.
  • In-Card Countdown Timer & Stopwatch: Type timer [duration] (e.g. timer 5m, timer 1m30s, timer 45s) or stopwatch for interactive controls with audio alerts.
  • GitHub Repository Inspector: Type repo [owner/repo] or github [owner/repo] (e.g. repo facebook/react, repo vercel/next.js) to view stars, forks, issues, and license details.
  • Movies, Tickets & Streaming: Type movie [title], tickets [title], or stream [title] for IMDb ratings, plot summaries, Fandango tickets, and streaming platforms.
  • OpenTable Reservations: Type reserve [restaurant or cuisine] [city] (e.g., reserve steak Orlando) to book tables directly.
  • General Knowledge: Type any entity or question (e.g., MrBeast, Quantum Computing) to query Wiktionary, Wikipedia, and YouTube metrics simultaneously.
  • Sunset & Solar Telemetry: Type sunset [location], sunrise [location], or solar [location] for twilight times, solar noon, day duration, and golden hour windows.
  • Postal Code Geocoder (Zippopotam): Type zip [code] or postal [code] (e.g., zip 90210, postal 32801) for town, state, and geographic coordinates.
  • Cute Animals & Ducks: Type dog, cat, or duck for instant cute pet photography and duck images.
  • College & University Directory (Hipo): Type college [name] or university [name] (e.g., university Harvard, college MIT) for official `.edu` portals and campus locations.
  • Live Forex Converter (Frankfurter): Type convert [amount] [from] to [to] (e.g. convert 100 USD to EUR, 50 GBP to JPY) for live currency conversions.
  • Dynamic QR Code Generator: Type qr [text or url] (e.g. qr https://vaii-two.vercel.app) to generate an instant scannable QR card with direct PNG download.
  • ISS Telemetry (Where the ISS at): Type iss or orbit for real-time orbital velocity (km/h), altitude, latitude, and longitude coordinates.
  • NASA APOD (Astronomy): Type space or nasa to fetch NASA's Astronomy Picture of the Day with celestial explanations.
  • Advice & Quotes (Advice Slip): Type advice for instant random pearls of wisdom.
  • Age Demographics (Agify): Type age [name] (e.g., age Logan, age Alex) to predict estimated age and sample size metrics.
  • Dictionary & Phonetics: Type define [word] (e.g., define serendipity) for definitions, parts of speech, examples, and audio pronunciation.
  • Country & Flags (REST Countries & World Bank): Type country [name] for official flags, capitals, World Bank live population metrics, and currencies.
  • Drink & Cocktails (TheCocktailDB): Type drink [name] or random drink for ingredients, measures, and preparation recipes.
  • Public IP & Network (ipapi): Type my ip or ip lookup to display your live IP, ISP, and geographic network parameters.
  • Interactive Trivia Quiz: Type trivia or quiz to answer interactive multiple-choice questions.
  • PC Gaming Freebies & Deals: Type free games or deals for live discounts and free game trackers.
  • Jokes (icanhazdadjoke): Type joke or make me laugh for clean one-liners.
  • Music Previews (iTunes): Type song [title] (e.g., song Bohemian Rhapsody) to play a 30-second audio preview.
  • Anime & Manga (AniList): Type anime [title] or manga [title] for scores, episodes, and summaries.
  • Pokémon Dex (PokéAPI): Type pokemon [name/id] for pixel sprites, typings, and stats.
  • Books (Open Library): Type book [title] to pull cover art and authors.
  • Live News (GNews): Type top news or news about [topic].
  • App & Site Launcher: Type open [site] (e.g., open YouTube, open Minecraft).
  • Location & Weather: Type weather [location], time in [city], or City, State.
  • Math & Conversions: Enter equations like (12 * 4) / 2 or conversions like 193 lbs to kg.
  • Language Translation: Type [phrase] to [language] (e.g., hello to spanish).
  • Crypto & Stocks: Type BTC, ETH, or price of AAPL.
  • Local Food Search: Type order burger or order from Wendy's for GPS DoorDash routing.
  • Image Generation: Type draw [prompt] to render AI art.
  • Notes Engine: Type note: [your text] to save local notes, and show notes to view.

✨ Gemini Ecosystem Mode

  • Select Gemini Ecosystem on the mode switcher to engage persistent, multi-turn AI chat threads.
  • Custom Instructions: Click the gear icon (⚙️) next to Gemini to set long-term system instructions or personality guidelines.
  • Thread Management: Access historical chat sessions via the scroll icon (📜) or start a new thread using the edit icon (📝).
  • Model Fallback Matrix: Cascades from Gemini 3.7 Flash down to Gemma models automatically if quota limits are reached.

🎙️ Multimodal & Audio Tools

  • Microphone (🎙️): Activates speech-to-text input and enables automatic text-to-speech voice playback for responses.
  • Camera / Vision (📷): Upload any image file and type a prompt to analyze visual input using the Gemini Vision matrix.
  • Text-to-Speech (🔊): Click the TTS button on active response outputs to read back text cleanly without markdown tags or emojis.
